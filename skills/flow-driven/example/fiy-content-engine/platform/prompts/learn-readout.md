# Run ref — learn readout

**Step**: `learn` · **rung 3**

Fourteen days after publication, write `items/<slug>/readout.md`.

**Structure**:

1. **The hypothesis, quoted verbatim** from the card at intake. Do not paraphrase it — a
   paraphrase is how a hypothesis quietly becomes whatever happened.
2. **What happened**: the numbers with their denominators, and the qualitative signal
   (replies, questions, what people argued with).
3. **The call**: confirmed / disconfirmed / inconclusive. "Inconclusive" is the honest
   answer more often than it gets used.
4. **What we would do differently** — one thing, specific.
5. **Does this change the audience map?** If yes, propose the edit to
   `platform/context/audience-map.md` and flag it for Dana. This is how the platform
   compounds.

**Rules**: never attribute a business outcome to one piece. If the readout raises a new
question worth writing about, create a **new** intake card — this item goes to `shipped`.
